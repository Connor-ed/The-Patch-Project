# The Patch Project
![newtpp](https://github.com/user-attachments/assets/8a1c5fe7-738b-4a4a-9f89-2d48b626ce5b)

The Patch Project started as The Crave Patch Project in early 2025. After purchasing a Behringer Crave and finding no patch sheets that were easy to follow, I built this app to hold and preview patches I had made. I chose to open source it so others could use and contribute to it.

## Supported Synths

| Synth Name | Manufacturer | Status | Patches |
|------------|--------------|--------|---------|
| Crave | Behringer | ✅ Supported | 8 |

![BCS_DEMO](https://github.com/user-attachments/assets/0144d8d2-9043-4c6f-9425-7ff681362aa5)

## Contributing

Want to add patches? You can upload directly inside the app. All assets needed to get started are in the [source code](https://github.com/Connor-ed/The-Patch-Project). We use [GDevelop](https://gdevelop.io) to build this app.

Please read and follow our [Contributor Covenant Code of Conduct](https://github.com/Connor-ed/The-Crave-Patch-Project/blob/main/CODE_OF_CONDUCT.md) before contributing.
